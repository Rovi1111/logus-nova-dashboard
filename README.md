# Дашборд диспетчера РЦ «Восток»

Интерактивный экран диспетчера распределительного центра ритейлера — демо команды для студенческого чемпионата по логистике Logus Nova 2026. Страница показывает, хватит ли ворот и людей на ближайшие 8 часов, подсказывает, что сделать при очереди, и позволяет проверить сценарий «что если», двигая ползунки «Открыто ворот» и «Людей на смене». Переключатель «Приёмка | Отгрузка» меняет поток машин и список ближайших рейсов.

Все данные синтетические: прогноз машин по часам, госномера, поставщики и магазины придуманы для демонстрации. Модель упрощённая — разгрузка одной машины занимает 45 минут, на одни ворота нужно 3 человека, очередь копится по часам с начала суток, текущее время зафиксировано на 14:00. Весь расчёт идёт в браузере, сервер и интернет не нужны.

Опубликованная версия: https://rovi1111.github.io/logus-nova-dashboard/ (тот же адрес зашит в QR-код). Чтобы открыть локально, достаточно запустить `index.html` в любом современном браузере — это один файл без зависимостей, сборки и внешних ресурсов.
