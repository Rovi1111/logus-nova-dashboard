# Дашборд диспетчера РЦ «Восток»

Интерактивный экран диспетчера распределительного центра ритейлера — демо команды для студенческого чемпионата по логистике Logus Nova 2026. Страница показывает очередь и ожидание на ближайшие 8 часов, 7 или 14 дней, подсказывает, сколько ворот и людей добавить, и позволяет проверить сценарии «что если»: число ворот и людей, рост потока машин, работа со слотами и без них. Переключатель «Приёмка | Отгрузка» меняет поток машин и список ближайших рейсов.

Все данные синтетические: прогноз и факт по часам, госномера, поставщики и магазины придуманы для демонстрации. Модель упрощённая: разгрузка одной машины занимает 45 минут, на одни ворота нужно 3 человека. Очередь до текущего часа считается как факт и от ползунков не зависит, ползунки меняют только будущее. Весь расчёт идёт в браузере, сервер и интернет не нужны.

Опубликованная версия: https://rovi1111.github.io/logus-nova-dashboard/ (тот же адрес зашит в QR-код). Страница берёт текущее время устройства; чтобы показать конкретный час, добавьте к адресу `?now=14`. Чтобы открыть локально, достаточно запустить `index.html` в любом современном браузере — это один файл без зависимостей, сборки и внешних ресурсов.
